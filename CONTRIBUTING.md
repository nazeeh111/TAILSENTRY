# Contributing

Run the numerical tests and saved-artifact verifier. Keep loss models, density ratios, support assumptions and sample-accounting explicit. Preserve failed experiments. Never use the label SAIS for the CE variants; see the isolated reproduction fidelity record. New performance claims need fresh fixed seeds, all training costs and applicable conditional/union baselines. Do not transfer probability confidence guarantees to plug-in quantiles or severity.

The existing published-result dataset is immutable. Add new run directories and source hashes. A source correction does not authorize replacing unfavorable holdout results. Current code intentionally contains fixes beyond the preserved executed source versions; verify those snapshots separately.
