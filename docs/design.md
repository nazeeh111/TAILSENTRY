# Interface direction

A research instrument: near-black surfaces, phosphor green signals, sharply ruled geometry, restrained monospace type. No fake live telemetry, ornamental radar or animated catastrophe. One clear estimate, its interval and model status lead. Charts show recorded or freshly computed numbers. Mode contribution and sampling allocation are labelled separately. Keyboard-visible focus, accessible contrast, real errors, narrow-screen layout and reduced motion are required. The interface runs locally against the Python engine; it is not hosted.
